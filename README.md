# Gamified FAANG DSA Tracker 🚀

A modern, highly engaging DSA / FAANG interview preparation tracker based on a curated 23-day preparation schedule. This platform acts as a personal dashboard where you can track your daily progress, watch curated YouTube tutorials, revise tricky topics, and stay motivated using gamified elements like streaks and achievements.

## 🔗 Live Deployment
**[View the Live Application on Vercel](https://dsa-tracker-phi-lac.vercel.app)**

---

## ✨ Features

- **Strict Curriculum Engine:** Maps 96 videos, 3 practice days, and 22 bonus courses directly from the provided source PDF.
- **Daily Focus Mode:** "Today's Mission" highlights exactly what you need to complete each day, keeping you on track without overwhelming you.
- **Gamified Experience:** 
  - Earn achievements like *Consistency is Key* or *FAANG Ready*.
  - Track your current and longest study streak.
  - Celebrate success with dynamic confetti animations upon daily and full-curriculum completions.
- **Comprehensive Statistics:** Get granular insights into your performance broken down by problem difficulty and topic categories (Arrays, Trees, DP, etc.).
- **Global Search & Filter:** Easily search through the entire library of 96 problems or filter by difficulty and completion status.
- **Revision Queue:** Mark problems as "Needs Revision" and revisit them in a dedicated space.
- **Bonus Deep Dives:** Access 22 extra-long, topic-specific full courses for mastering weak areas.
- **Data Persistence:** All progress is stored locally in your browser so you can pick up where you left off. Includes functionality to safely export and import your progress data.

## 🛠️ Technology Stack

- **Framework:** React 19 + Vite
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4, Lucide React (Icons)
- **Animations:** Framer Motion, Canvas Confetti
- **Charts:** Recharts

## 🚀 Getting Started Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Mishra07adi/DSA_Tracker.git
   cd DSA_Tracker
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
